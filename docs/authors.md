## Contribute

Contributions of every size are welcome:

- Report a bug or request a feature on [GitHub Issues](https://github.com/xinp-hub/pydiggs/issues)
- Fix a bug or add a feature with a pull request
- Improve the documentation: every page has an **Edit this page** button
- Share how you use pyDIGGS

Start with the [Contributing guide](contributing.md).
