# Video tutorials

Short narrated videos of pyDIGGS at work, one per feature. Every video has English
captions, chapters and a full transcript, and plays from this site: no third-party player
and no cookies.

The videos are made from scripts in
[`docs/tutorials/`](https://github.com/xinp-hub/pydiggs/tree/master/docs/tutorials) each
time the documentation is published. The commands you see really ran against the
documented version, and a video whose output no longer matches its script stops the
build, so the videos cannot fall behind the software. The example files are written for
the purpose; none holds project data.
