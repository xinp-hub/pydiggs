# Stay updated

Hear about new pyDIGGS releases in the way that suits you. Every option below is free,
and you can stop at any time.

## Watch releases on GitHub

On the [pyDIGGS repository](https://github.com/xinp-hub/pydiggs), choose
**Watch → Custom → Releases**. GitHub then emails you each new release, with its notes,
and nothing else from the repository.

## Feeds

Add either feed to an RSS reader, a chat integration or your own tooling:

| Feed | URL |
|---|---|
| GitHub releases (with release notes) | <https://github.com/xinp-hub/pydiggs/releases.atom> |
| PyPI releases | <https://pypi.org/rss/project/pydiggs/releases.xml> |

## Email updates

A short email for each feature release (1.6.0, 1.7.0, …): what changed for people who
integrate pyDIGGS, and what is coming next. Patch releases are not emailed.

## What a release contains

Each release's notes come from the [changelog](history.md). pyDIGGS releases only add
features: code written against an earlier 1.x release keeps working.
