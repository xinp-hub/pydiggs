pyDIGGS · Testing DIGGS support

DIGGS conformance suite, in your browser

Self-tested, and nothing leaves your browser

The same three steps as pydiggs conformance new, grade and verify, run by pyDIGGS inside this tab (on Pyodide, Python compiled to WebAssembly). The files you choose are read here and are never uploaded: there is no server behind this page. To start, the page downloads Pyodide from jsDelivr and pyDIGGS 1.17.0 from PyPI, each checked against a pinned hash; after that it makes no request at all.

A result is self-tested. It shows that a file passed a published test. It does not show which software wrote the file, and it is not a certification by the DIGGS committee or the ASCE Geo-Institute. The evidence says so in its own words.

Prefer the command line? The same suite as pydiggs conformance; a challenge made here grades there, and back.
